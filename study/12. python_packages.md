## 1. 패키지와 모듈의 개념

### 1.1 모듈(Module)이란?

**모듈**은 파이썬 코드가 담긴 파일(`.py`)입니다. 함수, 클래스, 변수 등을 정의할 수 있습니다.

```python
# math_utils.py (모듈)
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

PI = 3.14159
```

### 1.2 패키지(Package)란?

**패키지**는 여러 모듈을 그룹화한 디렉토리입니다. `__init__.py` 파일이 있는 디렉토리가 패키지가 됩니다.

```
my_package/          # 패키지 디렉토리
├── __init__.py      # 패키지 초기화 파일 (필수)
├── module1.py       # 모듈 1
├── module2.py       # 모듈 2
└── subpackage/      # 서브패키지
    ├── __init__.py
    └── module3.py
```

### 1.3 패키지 vs 모듈

| 구분 | 모듈 | 패키지 |
|------|------|--------|
| **형태** | 단일 `.py` 파일 | 디렉토리 |
| **필수 파일** | 없음 | `__init__.py` |
| **용도** | 관련 기능을 하나의 파일에 | 여러 모듈을 그룹화 |
| **예시** | `utils.py` | `utils/` |

## 2. 패키지 생성하기

### 2.1 기본 패키지 생성

#### 단계 1: 디렉토리 생성
```bash
mkdir my_package
cd my_package
```

#### 단계 2: `__init__.py` 파일 생성
```python
# my_package/__init__.py
"""
My Package - 패키지 설명
"""

__version__ = "0.1.0"
__author__ = "Your Name"
```

#### 단계 3: 모듈 추가
```python
# my_package/utils.py
def greet(name):
    return f"Hello, {name}!"

def add(a, b):
    return a + b
```

```python
# my_package/models.py
class User:
    def __init__(self, name):
        self.name = name
    
    def get_name(self):
        return self.name
```

### 2.2 패키지 구조 예제

```
my_package/
├── __init__.py
├── utils.py
├── models.py
└── config.py
```

## 3. `__init__.py` 파일의 역할

### 3.1 기본 역할

`__init__.py` 파일은 디렉토리를 패키지로 인식하게 만듭니다.

#### 빈 `__init__.py` (최소 구성)
```python
# my_package/__init__.py
# 빈 파일이어도 패키지로 인식됨
```

### 3.2 패키지 초기화

패키지가 임포트될 때 실행되는 코드를 작성할 수 있습니다.

```python
# my_package/__init__.py
print("패키지가 임포트되었습니다!")

# 패키지 레벨 변수
VERSION = "0.1.0"
AUTHOR = "Your Name"
```

### 3.3 패키지 레벨 임포트

패키지에서 자주 사용하는 모듈/클래스를 직접 임포트할 수 있게 합니다.

```python
# my_package/__init__.py
from .utils import greet, add
from .models import User

# 패키지를 임포트하면 자동으로 사용 가능
__all__ = ['greet', 'add', 'User']
```

**사용 예시:**
```python
# 사용하는 쪽
import my_package

# __init__.py에서 임포트한 것들을 바로 사용 가능
my_package.greet("홍길동")
user = my_package.User("김철수")
```

### 3.4 패키지 초기화 함수

```python
# my_package/__init__.py
def initialize():
    """패키지 초기화 함수"""
    print("패키지 초기화 완료")

def get_version():
    """버전 정보 반환"""
    return "0.1.0"
```

## 4. 패키지 임포트 방법

### 4.1 기본 임포트

#### 전체 패키지 임포트
```python
import my_package

# 사용: my_package.module.function()
my_package.utils.greet("홍길동")
```

#### 패키지 내 모듈 임포트
```python
from my_package import utils
from my_package import models

# 사용
utils.greet("홍길동")
user = models.User("김철수")
```

#### 특정 함수/클래스 임포트
```python
from my_package.utils import greet, add
from my_package.models import User

# 사용
greet("홍길동")
result = add(1, 2)
user = User("김철수")
```

### 4.2 별칭(Alias) 사용

```python
import my_package as mp
from my_package import utils as u

mp.utils.greet("홍길동")
u.greet("홍길동")
```

### 4.3 모든 것 임포트 (권장하지 않음)

```python
from my_package import *  # 권장하지 않음

# __all__이 정의되어 있으면 그것만 임포트됨
```

## 5. 서브패키지(Subpackage)

### 5.1 서브패키지 구조

```
my_package/
├── __init__.py
├── utils.py
├── models.py
└── database/              # 서브패키지
    ├── __init__.py
    ├── connection.py
    └── queries.py
```

### 5.2 서브패키지 임포트

```python
# 서브패키지 전체 임포트
from my_package import database

# 서브패키지 내 모듈 임포트
from my_package.database import connection

# 서브패키지 내 함수/클래스 임포트
from my_package.database.connection import connect_db
```

### 5.3 중첩 서브패키지

```
my_package/
├── __init__.py
└── api/
    ├── __init__.py
    ├── v1/                # 중첩 서브패키지
    │   ├── __init__.py
    │   └── endpoints.py
    └── v2/
        ├── __init__.py
        └── endpoints.py
```

```python
from my_package.api.v1 import endpoints
from my_package.api.v2.endpoints import get_data
```

## 6. 패키지 내 모듈 간 임포트

### 6.1 상대 임포트 (Relative Import)

패키지 내부에서 다른 모듈을 임포트할 때 사용합니다.

```python
# my_package/utils.py
def helper():
    return "helper function"

# my_package/models.py
from .utils import helper  # 같은 패키지 내 utils 모듈

class User:
    def __init__(self):
        self.helper = helper()
```

### 6.2 상대 임포트 문법

```python
# 현재 패키지 내 모듈
from .module import something

# 상위 패키지
from ..parent_module import something

# 같은 레벨의 다른 패키지
from ..sibling_package import something

# 서브패키지
from .subpackage.module import something
```

### 6.3 절대 임포트 (Absolute Import)

```python
# my_package/models.py
from my_package.utils import helper  # 절대 경로

class User:
    def __init__(self):
        self.helper = helper()
```

### 6.4 상대 vs 절대 임포트

| 구분 | 상대 임포트 | 절대 임포트 |
|------|-----------|-----------|
| **문법** | `from .module import` | `from package.module import` |
| **장점** | 패키지 이름 변경 시 유연 | 명확하고 이해하기 쉬움 |
| **권장** | 패키지 내부에서만 | 일반적으로 권장 |

## 7. 패키지 구조 예제

### 7.1 간단한 패키지

```
calculator/
├── __init__.py
├── basic.py      # 기본 연산
└── advanced.py   # 고급 연산
```

```python
# calculator/__init__.py
from .basic import add, subtract
from .advanced import power, sqrt

__all__ = ['add', 'subtract', 'power', 'sqrt']
```

```python
# calculator/basic.py
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b
```

```python
# calculator/advanced.py
def power(base, exp):
    return base ** exp

def sqrt(number):
    return number ** 0.5
```

**사용:**
```python
from calculator import add, power

result1 = add(1, 2)      # 3
result2 = power(2, 3)     # 8
```

│   ├── __init__.py

    ├── __init__.py
    ├── validators.py

# webapp/models/__init__.py
from .user import User

```

# webapp/models/user.py
from ..utils.validators import validate_email

class User:

# webapp/services/user_service.py
from ..models import User  # 상위 패키지의 models 서브패키지

def create_user(email):
    return User(email)
```

## 8. 패키지 배포

### 8.1 배포용 패키지 구조

```
my_package/
├── my_package/           # 소스 코드 패키지
│   ├── __init__.py
│   ├── module1.py
│   └── module2.py
├── tests/                # 테스트 코드
│   ├── __init__.py

├── docs/                 # 문서

├── setup.cfg
├── README.md
├── LICENSE
└── requirements.txt
```

### 8.2 `setup.py` 작성

```python
from setuptools import setup, find_packages

setup(
    name="my_package",
    version="0.1.0",
    author="Your Name",
    description="패키지 설명",
    packages=find_packages(),  # 자동으로 패키지 찾기
    python_requires=">=3.8",
    install_requires=[
        "requests>=2.28.0",
    ],
)
```

```bash
pip install .
```

```bash
python setup.py sdist bdist_wheel

```

## 9. 네임스페이스 패키지 (Namespace Package)

### 9.1 네임스페이스 패키지란?

`__init__.py` 파일 없이도 패키지로 인식되는 방식입니다. (Python 3.3+)

```
namespace_pkg/
├── part1/
│   └── module1.py
└── part2/
    └── module2.py
```

### 9.2 사용 예시

```python
# part1과 part2가 같은 네임스페이스에 있음
from namespace_pkg.part1 import module1
from namespace_pkg.part2 import module2
```

## 10. 패키지 임포트 경로

### 10.1 Python 경로 (sys.path)

Python은 다음 순서로 모듈을 찾습니다:

1. 현재 디렉토리
2. `PYTHONPATH` 환경 변수
3. 표준 라이브러리 디렉토리
4. site-packages 디렉토리

```python
import sys
print(sys.path)  # Python이 모듈을 찾는 경로 목록
```

### 10.2 경로 확인

```python
import my_package
print(my_package.__file__)      # 패키지 파일 경로
print(my_package.__path__)      # 패키지 경로 목록
```

## 11. 패키지 개발 모범 사례

### 11.1 `__all__` 사용

패키지에서 공개할 항목을 명시합니다.

```python
# my_package/__init__.py
from .utils import greet, add
from .models import User

__all__ = ['greet', 'add', 'User']  # from package import * 시 이것만 임포트
```

### 11.2 버전 관리

```python
# my_package/__init__.py
__version__ = "0.1.0"
__version_info__ = (0, 1, 0)
```

### 11.3 문서화

```python
# my_package/__init__.py
"""
My Package - 패키지 설명

이 패키지는 다음과 같은 기능을 제공합니다:
- 유틸리티 함수
- 데이터 모델
- 서비스 클래스
"""

__version__ = "0.1.0"
```

### 11.4 순환 임포트 방지

#### 나쁜 예 (순환 임포트)
```python
# module1.py
from module2 import function2

# module2.py
from module1 import function1  # 순환 임포트!
```

#### 좋은 예
```python
# module1.py
def function1():
    from module2 import function2  # 함수 내부에서 임포트
    return function2()

# 또는 공통 모듈로 분리
```

### 11.5 패키지 초기화 최소화

`__init__.py`에서 무거운 작업을 피하고, 필요할 때만 임포트합니다.

```python
# my_package/__init__.py
# 나쁜 예: 모든 것을 즉시 임포트
from .heavy_module import HeavyClass  # 무거운 임포트

# 좋은 예: 지연 임포트
def get_heavy_class():
    from .heavy_module import HeavyClass
    return HeavyClass
```

## 13. 패키지 임포트 문제 해결

### 13.1 ModuleNotFoundError

**문제:**
```python
ModuleNotFoundError: No module named 'my_package'
```

**해결:**
- 패키지가 `sys.path`에 있는지 확인
- `PYTHONPATH` 환경 변수 설정
- 개발 모드로 설치: `pip install -e .`

### 13.2 상대 임포트 오류

**문제:**
```python
ImportError: attempted relative import with no known parent package
```

**해결:**
- 스크립트로 직접 실행하지 말고 모듈로 실행: `python -m package.module`
- 절대 임포트 사용

### 13.3 순환 임포트

**문제:**
```python
ImportError: cannot import name 'X' from partially initialized module
```

**해결:**
- 임포트 순서 변경
- 함수/클래스 내부에서 임포트
- 공통 모듈로 분리

## 14. 실전 예제: 완전한 패키지 구조

### 14.1 패키지 구조

```
calculator/
├── calculator/
│   ├── __init__.py
│   ├── basic.py
│   ├── advanced.py
│   └── utils/
│       ├── __init__.py
│       └── helpers.py
├── tests/
│   ├── __init__.py
│   ├── test_basic.py
│   └── test_advanced.py
├── setup.py
├── README.md
└── requirements.txt
```

### 14.2 코드 예제

```python
# calculator/__init__.py
"""
Calculator Package - 계산기 패키지
"""

__version__ = "1.0.0"

from .basic import add, subtract, multiply, divide
from .advanced import power, sqrt

__all__ = ['add', 'subtract', 'multiply', 'divide', 'power', 'sqrt']
```

```python
# calculator/basic.py
"""기본 연산 함수들"""

def add(a, b):
    """덧셈"""
    return a + b

def subtract(a, b):
    """뺄셈"""
    return a - b

def multiply(a, b):
    """곱셈"""
    return a * b

def divide(a, b):
    """나눗셈"""
    if b == 0:
        raise ValueError("0으로 나눌 수 없습니다")
    return a / b
```

```python
# calculator/advanced.py
"""고급 연산 함수들"""

from .utils.helpers import validate_positive

def power(base, exp):
    """거듭제곱"""
    return base ** exp

def sqrt(number):
    """제곱근"""
    validate_positive(number)
    return number ** 0.5
```

```python
# calculator/utils/__init__.py
from .helpers import validate_positive

__all__ = ['validate_positive']
```

```python
# calculator/utils/helpers.py
"""유틸리티 함수들"""

def validate_positive(number):
    """양수인지 검증"""
    if number < 0:
        raise ValueError("음수는 허용되지 않습니다")
```

### 14.3 사용 예제

```python
# 사용하는 쪽 코드
from calculator import add, power, sqrt

# 기본 연산
result1 = add(1, 2)        # 3
result2 = power(2, 3)      # 8
result3 = sqrt(16)         # 4.0

# 또는
import calculator
result = calculator.add(1, 2)
```

## 15. 요약

### 핵심 개념

1. **모듈**: 단일 `.py` 파일
2. **패키지**: `__init__.py`가 있는 디렉토리
3. **서브패키지**: 패키지 내부의 패키지

### 패키지 생성 단계

1. 디렉토리 생성
2. `__init__.py` 파일 생성
3. 모듈 파일 추가
4. 필요시 `setup.py` 작성

### 임포트 방법

- **전체 패키지**: `import package`
- **모듈**: `from package import module`
- **함수/클래스**: `from package.module import function`
- **상대 임포트**: `from .module import something`

### 모범 사례

- ✅ `__all__`로 공개 API 명시
- ✅ 버전 정보 관리
- ✅ 문서화
- ✅ 순환 임포트 방지
- ✅ 테스트 코드 작성

### 주의사항

- ⚠️ `__init__.py`는 패키지 인식에 필수 (Python 3.3 이전)
- ⚠️ 상대 임포트는 패키지 내부에서만 사용
- ⚠️ 순환 임포트 주의
- ⚠️ 무거운 임포트는 지연 로딩
