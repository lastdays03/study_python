## 1. Matplotlib 소개

### 1.1 Matplotlib란?

**Matplotlib**는 파이썬에서 데이터 시각화를 위한 가장 널리 사용되는 라이브러리입니다. MATLAB 스타일의 인터페이스를 제공하며, 다양한 종류의 그래프와 차트를 생성할 수 있습니다.

### 1.2 Matplotlib의 주요 특징

- **다양한 플롯 타입**: 선 그래프, 막대 그래프, 산점도, 히스토그램 등
- **고품질 출력**: PDF, PNG, SVG 등 다양한 형식 지원
- **커스터마이징**: 색상, 스타일, 레이블 등 세밀한 제어 가능
- **인터랙티브**: Jupyter Notebook에서 대화형 플롯 지원
- **확장성**: Seaborn, Plotly 등 다른 라이브러리와 통합 가능

### 1.3 설치

```bash
pip install matplotlib
```

### 1.4 기본 임포트

```python
import matplotlib.pyplot as plt
import numpy as np
```

## 2. 플롯 생성 및 종류

### 2.1 선 그래프 (Line Plot)

**설명**: 데이터 포인트를 선으로 연결하여 추세를 보여주는 가장 기본적인 플롯입니다. 시계열 데이터나 연속적인 데이터를 시각화할 때 사용합니다.

**사용 사례**:
- 시계열 데이터 시각화 (주가, 온도 변화 등)
- 함수 그래프 그리기
- 추세 분석
- 데이터 변화 추이 확인
- 실험 결과 시각화

```python
import matplotlib.pyplot as plt
import numpy as np

# 기본 선 그래프
x = np.linspace(0, 10, 100)
y = np.sin(x)

plt.plot(x, y)
plt.show()

# 제목과 레이블 추가
plt.plot(x, y)
plt.title('Sine Wave')
plt.xlabel('X axis')
plt.ylabel('Y axis')
plt.show()
```

### 2.2 산점도 (Scatter Plot)

**설명**: 두 변수 간의 관계를 점으로 표시하는 플롯입니다. 상관관계나 패턴을 파악하는 데 유용합니다.

**사용 사례**:
- 두 변수 간 상관관계 분석
- 클러스터링 결과 시각화
- 이상치 탐지
- 데이터 분포 확인
- 회귀 분석 전 데이터 탐색

```python
# 기본 산점도
x = np.random.randn(100)
y = np.random.randn(100)

plt.scatter(x, y)
plt.xlabel('X')
plt.ylabel('Y')
plt.title('Scatter Plot')
plt.show()

# 크기와 색상으로 추가 정보 표현
sizes = np.random.randint(50, 200, 100)
colors = np.random.randn(100)

plt.scatter(x, y, s=sizes, c=colors, alpha=0.6)
plt.colorbar()  # 컬러바 추가
plt.show()
```

### 2.3 막대 그래프 (Bar Plot)

**설명**: 범주형 데이터를 막대로 표현하는 그래프입니다. 카테고리별 값을 비교할 때 사용합니다.

**사용 사례**:
- 카테고리별 비교
- 순위 시각화
- 빈도수 표시
- 성과 비교
- 리포트 및 프레젠테이션

```python
# 수직 막대 그래프
categories = ['A', 'B', 'C', 'D', 'E']
values = [23, 45, 56, 78, 32]

plt.bar(categories, values)
plt.xlabel('Categories')
plt.ylabel('Values')
plt.title('Bar Chart')
plt.show()

# 수평 막대 그래프
plt.barh(categories, values)
plt.xlabel('Values')
plt.ylabel('Categories')
plt.title('Horizontal Bar Chart')
plt.show()
```

### 2.4 히스토그램 (Histogram)

**설명**: 데이터의 분포를 막대로 표현하는 그래프입니다. 연속적인 데이터의 빈도 분포를 확인할 때 사용합니다.

**사용 사례**:
- 데이터 분포 분석
- 정규성 검사
- 이상치 탐지
- 통계 분석
- 데이터 품질 검사

```python
# 기본 히스토그램
data = np.random.normal(100, 15, 1000)

plt.hist(data, bins=30)
plt.xlabel('Value')
plt.ylabel('Frequency')
plt.title('Histogram')
plt.show()

# 여러 히스토그램 비교
data1 = np.random.normal(100, 15, 1000)
data2 = np.random.normal(120, 20, 1000)

plt.hist(data1, bins=30, alpha=0.5, label='Group 1')
plt.hist(data2, bins=30, alpha=0.5, label='Group 2')
plt.legend()
plt.show()
```

### 2.5 박스 플롯 (Box Plot)

**설명**: 데이터의 분포를 사분위수, 중앙값, 이상치로 표현하는 그래프입니다. 여러 그룹의 분포를 비교할 때 유용합니다.

**사용 사례**:
- 여러 그룹의 분포 비교
- 이상치 탐지
- 사분위수 확인
- 통계 요약 시각화
- 데이터 품질 검사

```python
# 기본 박스 플롯
data = [np.random.normal(0, std, 100) for std in range(1, 4)]

plt.boxplot(data, labels=['Group 1', 'Group 2', 'Group 3'])
plt.ylabel('Value')
plt.title('Box Plot')
plt.show()
```


### 2.6 파이 차트 (Pie Chart)

**설명**: 전체에 대한 각 부분의 비율을 원형으로 표현하는 차트입니다. 구성 비율을 시각화할 때 사용합니다.

**사용 사례**:
- 구성 비율 시각화
- 카테고리별 비중 표시
- 리포트 및 프레젠테이션
- 설문 결과 시각화
- 예산/매출 구성

```python
# 기본 파이 차트
labels = ['A', 'B', 'C', 'D']
sizes = [15, 30, 45, 10]
colors = ['#ff9999', '#66b3ff', '#99ff99', '#ffcc99']

plt.pie(sizes, labels=labels, colors=colors, autopct='%1.1f%%', startangle=90)
plt.title('Pie Chart')
plt.show()

# 도넛 차트
plt.pie(sizes, labels=labels, colors=colors, autopct='%1.1f%%', 
        startangle=90, pctdistance=0.85)
centre_circle = plt.Circle((0,0), 0.70, fc='white')
fig = plt.gcf()
fig.gca().add_artist(centre_circle)
plt.show()
```

### 2.7 영역 그래프 (Area Plot)

**설명**: 선 그래프 아래 영역을 채워서 누적값이나 변화량을 강조하는 그래프입니다.

**사용 사례**:
- 누적 데이터 시각화
- 변화량 강조
- 여러 시리즈의 누적
- 트렌드 분석
- 스택 영역 그래프

```python
x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)

# 기본 영역 그래프
plt.fill_between(x, y1, alpha=0.5, label='sin')
plt.fill_between(x, y2, alpha=0.5, label='cos')
plt.legend()
plt.show()

# 스택 영역 그래프
y = np.array([np.sin(x), np.cos(x), np.sin(x)*np.cos(x)])
plt.stackplot(x, y, labels=['sin', 'cos', 'sin*cos'], alpha=0.7)
plt.legend(loc='upper left')
plt.show()
```

### 2.8 등고선 그래프 (Contour Plot)

**설명**: 3차원 데이터를 2차원 평면에 등고선으로 표현하는 그래프입니다. 높이, 온도, 압력 등의 분포를 시각화할 때 사용합니다.

**사용 사례**:
- 3D 데이터 2D 표현
- 지형도
- 온도/압력 분포
- 함수의 등고선
- 과학 데이터 시각화

```python
# 등고선 그래프
x = np.linspace(-5, 5, 100)
y = np.linspace(-5, 5, 100)
X, Y = np.meshgrid(x, y)
Z = np.sin(np.sqrt(X**2 + Y**2))

plt.contour(X, Y, Z, levels=20)
plt.colorbar()
plt.title('Contour Plot')
plt.show()

# 채워진 등고선
plt.contourf(X, Y, Z, levels=20, cmap='viridis')
plt.colorbar()
plt.title('Filled Contour Plot')
plt.show()
```

### 2.9 3D 표면 그래프

**설명**: 3차원 데이터를 3D 표면으로 표현하는 그래프입니다. 3D 함수나 지형을 시각화할 때 사용합니다.

**사용 사례**:
- 3D 함수 시각화
- 지형 표현
- 과학 데이터 시각화
- 복잡한 관계 표현
- 연구 및 분석

```python
from mpl_toolkits.mplot3d import Axes3D

fig = plt.figure(figsize=(10, 8))
ax = fig.add_subplot(111, projection='3d')

x = np.linspace(-5, 5, 50)
y = np.linspace(-5, 5, 50)
X, Y = np.meshgrid(x, y)
Z = np.sin(np.sqrt(X**2 + Y**2))

ax.plot_surface(X, Y, Z, cmap='viridis', alpha=0.8)
ax.set_xlabel('X')
ax.set_ylabel('Y')
ax.set_zlabel('Z')
ax.set_title('3D Surface Plot')
plt.show()
```

### 2.10 히트맵 (Heatmap)

**설명**: 2차원 데이터를 색상으로 표현하는 그래프입니다. 상관관계 행렬이나 데이터 매트릭스를 시각화할 때 사용합니다.

**사용 사례**:
- 상관관계 행렬 시각화
- 데이터 매트릭스 표현
- 클러스터링 결과
- 시간별 데이터 변화
- 대시보드

```python
# 히트맵
data = np.random.randn(10, 10)

plt.imshow(data, cmap='hot', interpolation='nearest')
plt.colorbar()
plt.title('Heatmap')
plt.show()

# 상관관계 히트맵
correlation_matrix = np.corrcoef(np.random.randn(5, 100))
plt.imshow(correlation_matrix, cmap='coolwarm', vmin=-1, vmax=1)
plt.colorbar()
plt.title('Correlation Heatmap')
plt.show()
```

### 2.11 3D 선 그래프

**설명**: 3차원 공간에서 선을 그려 3D 데이터를 시각화합니다. 궤적이나 경로를 표현할 때 사용합니다.

- 공간 데이터

```python
from mpl_toolkits.mplot3d import Axes3D

ax.set_zlabel('Z')
```

## 3. 플롯 스타일링

### 3.1 선 스타일

**설명**: 선 그래프의 스타일을 변경하여 다양한 표현이 가능합니다. 실선, 점선, 점-선 등 다양한 스타일을 지원합니다.

**사용 사례**:
- 여러 데이터 시리즈 구분
- 가독성 향상
- 스타일 가이드 준수
- 프레젠테이션용 그래프
- 논문/리포트 작성

```python
x = np.linspace(0, 10, 100)

# 다양한 선 스타일
plt.plot(x, np.sin(x), linestyle='-', label='solid')      # 실선
plt.plot(x, np.sin(x-1), linestyle='--', label='dashed')  # 점선
plt.plot(x, np.sin(x-2), linestyle='-.', label='dashdot') # 점-선
plt.plot(x, np.sin(x-3), linestyle=':', label='dotted')   # 점선
plt.legend()
plt.show()
```

### 3.2 마커 스타일

**설명**: 데이터 포인트에 마커를 표시하여 데이터를 더 명확하게 표현할 수 있습니다. 원, 사각형, 삼각형 등 다양한 마커를 사용할 수 있습니다.

**사용 사례**:
- 데이터 포인트 강조
- 여러 시리즈 구분
- 스파스 데이터 시각화
- 실험 데이터 표시
- 특정 포인트 강조

```python
x = np.linspace(0, 10, 20)

# 다양한 마커 스타일
plt.plot(x, np.sin(x), marker='o', label='circle')
plt.plot(x, np.sin(x-1), marker='s', label='square')
plt.plot(x, np.sin(x-2), marker='^', label='triangle')
plt.plot(x, np.sin(x-3), marker='*', label='star')
plt.legend()
plt.show()
```

### 3.3 색상 설정

**설명**: 플롯의 색상을 설정하여 시각적 구분을 명확하게 할 수 있습니다. 색상 이름, HEX 코드, RGB 값 등을 사용할 수 있습니다.

**사용 사례**:
- 브랜드 색상 적용
- 의미 있는 색상 매핑 (온도, 범주 등)
- 가독성 향상
- 색맹 고려한 색상 선택
- 일관된 색상 테마

```python
x = np.linspace(0, 10, 100)

# 색상 이름 사용
plt.plot(x, np.sin(x), color='red', label='red')
plt.plot(x, np.cos(x), color='blue', label='blue')

# HEX 코드 사용
plt.plot(x, np.sin(x-1), color='#FF5733', label='hex')

# RGB 튜플 사용
plt.plot(x, np.cos(x-1), color=(0.1, 0.2, 0.5), label='RGB')
plt.legend()
plt.show()
```

### 3.4 투명도 (Alpha)

**설명**: 플롯의 투명도를 조절하여 겹치는 부분을 명확하게 볼 수 있습니다. 0(완전 투명)부터 1(완전 불투명)까지 설정 가능합니다.

**사용 사례**:
- 겹치는 데이터 시각화
- 밀도 표현
- 여러 레이어 표현
- 히스토그램 비교
- 산점도에서 밀도 표현

```python
x = np.linspace(0, 10, 100)

# 투명도 조절
plt.plot(x, np.sin(x), alpha=0.5, label='alpha=0.5')
plt.plot(x, np.cos(x), alpha=0.8, label='alpha=0.8')
plt.fill_between(x, np.sin(x), alpha=0.3)  # 영역 채우기
plt.legend()
plt.show()
```

## 4. 서브플롯 (Subplots)

### 4.1 기본 서브플롯

**설명**: 하나의 Figure에 여러 개의 플롯을 배치하는 기능입니다. 여러 데이터를 한 번에 비교하거나 관련된 플롯을 함께 표시할 때 사용합니다.

**사용 사례**:
- 여러 데이터 시리즈 비교
- 관련 플롯 그룹화
- 대시보드 생성
- 리포트 작성
- 데이터 탐색

```python
# 2x2 서브플롯
fig, axes = plt.subplots(2, 2, figsize=(10, 8))

x = np.linspace(0, 10, 100)

axes[0, 0].plot(x, np.sin(x))
axes[0, 0].set_title('Sine')

axes[0, 1].plot(x, np.cos(x))
axes[0, 1].set_title('Cosine')

axes[1, 0].plot(x, np.tan(x))
axes[1, 0].set_title('Tangent')
```

- 리포트에 포함
- 논문 작성
- 프레젠테이션
- 문서화
- 공유

```python
x = np.linspace(0, 10, 100)
y = np.sin(x)

plt.plot(x, y)
plt.xlabel('X')
plt.ylabel('Y')
plt.title('Sine Wave')

# 다양한 형식으로 저장
plt.savefig('plot.png', dpi=300, bbox_inches='tight')  # PNG
plt.savefig('plot.pdf', bbox_inches='tight')  # PDF
plt.savefig('plot.svg', bbox_inches='tight')  # SVG
plt.savefig('plot.jpg', dpi=300, bbox_inches='tight')  # JPEG

plt.show()
```

## 14. 요약

### 14.1 핵심 개념

1. **기본 플롯**: `plot()`, `scatter()`, `bar()`, `hist()`, `boxplot()`
2. **서브플롯**: `subplots()`, `subplot2grid()`, `GridSpec`
3. **스타일링**: 색상, 마커, 선 스타일, 투명도
4. **축 설정**: `xlim()`, `ylim()`, `xticks()`, `yticks()`, `xlabel()`, `ylabel()`
5. **범례**: `legend()` 및 커스터마이징
6. **텍스트**: `text()`, `annotate()`, `title()`
7. **3D 플롯**: `Axes3D`, `plot_surface()`, `scatter3D()`
8. **이미지**: `imshow()`, 이미지 로드 및 표시
9. **애니메이션**: `FuncAnimation`
10. **스타일**: `plt.style.use()`, `rcParams`

### 14.2 주요 메서드 요약

#### 플롯 생성
- `plt.plot()`: 선 그래프
- `plt.scatter()`: 산점도
- `plt.bar()`: 막대 그래프
- `plt.hist()`: 히스토그램
- `plt.boxplot()`: 박스 플롯
- `plt.pie()`: 파이 차트

#### 서브플롯
- `plt.subplots()`: 서브플롯 생성
- `plt.subplot2grid()`: 그리드 기반 서브플롯
- `plt.tight_layout()`: 레이아웃 자동 조정

#### 스타일링
- `plt.xlabel()`, `plt.ylabel()`: 축 레이블
- `plt.title()`: 제목
- `plt.legend()`: 범례
- `plt.grid()`: 격자
- `plt.xlim()`, `plt.ylim()`: 축 범위

#### 저장 및 표시
- `plt.savefig()`: 그래프 저장
- `plt.show()`: 그래프 표시
