## 1. Seaborn: 통계적 데이터 시각화

**Seaborn**은 Matplotlib을 기반으로 만들어진 고수준(High-level) 데이터 시각화 라이브러리입니다. Matplotlib보다 더 아름다운 스타일과 색상 팔레트를 기본으로 제공하며, 통계적 정보를 시각화하는 데 특화되어 있습니다.

### 1.1 설치 및 임포트
```python
# 설치 (터미널)
# pip install seaborn

import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

# 한글 폰트 설정 (Mac 예시)
plt.rc('font', family='AppleGothic')
plt.rcParams['axes.unicode_minus'] = False
```

### 1.2 주요 특징
*   **Pandas DataFrame 친화적**: DataFrame의 컬럼명을 그대로 사용하여 그래프를 그릴 수 있습니다.
*   **세련된 디자인**: 기본 스타일이 Matplotlib보다 미려합니다.
*   **통계 기능 내장**: 회귀선, 신뢰구간 등을 자동으로 계산하여 표시해 줍니다.

> **Tip**: Seaborn은 **Pandas DataFrame**과 함께 사용할 때 가장 강력합니다. 데이터 전처리가 필요하다면 **[15. python_popular_libraries.md](15.%20python_popular_libraries.md)**의 Pandas 섹션을 참고하여 데이터를 알맞은 형태로 가공하세요.

### 1.3 주요 그래프 종류

#### 1.3.1 관계형 그래프 (Relational Plots)
두 변수 간의 관계를 보여줍니다.
*   **산점도 (`scatterplot`)**: 두 연속형 변수의 상관관계를 점으로 표현합니다.
    ```python
    sns.scatterplot(data=df, x='x_col', y='y_col', hue='category_col')
    ```
*   **선 그래프 (`lineplot`)**: 시간에 따른 변화나 추세를 보여줍니다.
    ```python
    sns.lineplot(data=df, x='time', y='value', hue='group')
    ```

#### 1.3.2 카테고리형 그래프 (Categorical Plots)
범주형 데이터의 분포나 통계량을 비교합니다.
*   **막대 그래프 (`barplot`)**: 범주별 평균과 신뢰구간을 보여줍니다.
    ```python
    sns.barplot(data=df, x='category', y='value')
    ```
*   **빈도 그래프 (`countplot`)**: 범주별 데이터 개수를 셉니다.
    ```python
    sns.countplot(data=df, x='category')
    ```
*   **박스 플롯 (`boxplot`)**: 데이터의 분포(4분위수, 이상치)를 요약합니다.
    ```python
    sns.boxplot(data=df, x='category', y='value')
    ```

#### 1.3.3 분포형 그래프 (Distribution Plots)
데이터의 분포 형태를 보여줍니다.
*   **히스토그램 (`histplot`)**: 구간별 빈도수를 막대로 표현합니다.
    ```python
    sns.histplot(data=df, x='value', kde=True) # kde=True: 밀도 곡선 추가
    ```

#### 1.3.4 매트릭스 그래프 (Matrix Plots)
*   **히트맵 (`heatmap`)**: 변수 간의 상관계수 행렬 등을 색상으로 표현할 때 유용합니다.
    ```python
    # 상관계수 계산
    corr = df.corr()
    # 히트맵 그리기
    sns.heatmap(corr, annot=True, cmap='coolwarm', fmt='.2f')
    ```

## 2. Folium: 지도 시각화

**Folium**은 Python 데이터를 Leaflet.js 라이브러리를 사용하여 인터랙티브한 지도로 시각화해주는 도구입니다. 웹 브라우저에서 확대/축소가 가능한 지도를 생성할 수 있습니다.

### 2.1 설치 및 임포트
```python
# 설치 (터미널)
# pip install folium

import folium
```

### 2.2 기본 지도 생성
`folium.Map` 객체를 생성하여 지도를 띄웁니다.
```python
# 위도, 경도 설정 (예: 서울 시청)
center = [37.5665, 126.9780]

# 지도 생성 (zoom_start: 초기 확대 레벨)
m = folium.Map(location=center, zoom_start=12)

# 지도 보기 (Jupyter Notebook)
m
```
*   **Tileset**: `tiles` 파라미터로 지도 스타일 변경 가능 ('OpenStreetMap', 'CartoDB positron' 등).

### 2.3 마커 추가 (Markers)
지도 위에 특정 위치를 표시합니다.
```python
# 기본 마커
folium.Marker(
    location=[37.5665, 126.9780],
    popup='서울 시청', # 클릭 시 나오는 팝업
    tooltip='클릭하세요', # 마우스 오버 시 나오는 툴팁
    icon=folium.Icon(color='blue', icon='info-sign')
).add_to(m)

# 원형 마커 (CircleMarker)
folium.CircleMarker(
    location=[37.5665, 126.9780],
    radius=10,
    color='red',
    fill=True,
    fill_color='red'
).add_to(m)
```

### 2.4 단계구분도 (Choropleth Maps)
행정구역과 같은 영역별로 데이터의 크기를 색상으로 표현합니다. GeoJSON 파일(지리 정보)이 필요합니다.

```python
# 예시 코드
folium.Choropleth(
    geo_data='seoul_municipalities.json', # GeoJSON 파일 경로
    data=df,                              # 데이터프레임
    columns=['구이름', '인구수'],           # [매핑할 키 컬럼, 값 컬럼]
    key_on='feature.properties.name',     # GeoJSON 내의 키 속성 경로
    fill_color='YlGn',                    # 색상 팔레트
    legend_name='인구수'
).add_to(m)
```

### 2.5 저장하기
생성된 지도를 HTML 파일로 저장할 수 있습니다.
```python
m.save('my_map.html')
```
