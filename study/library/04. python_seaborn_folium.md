## 1. Seaborn: 통계적 데이터 시각화

**Seaborn**은 Matplotlib을 기반으로 만들어진 고수준(High-level) 데이터 시각화 라이브러리입니다. Matplotlib보다 더 아름다운 스타일과 색상 팔레트를 기본으로 제공하며, 통계적 정보를 시각화하는 데 특화되어 있습니다.

### 1.1 설치 및 임포트
```python
# 설치 (터미널)
# pip install seaborn

import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

# 한글 폰트 설정 (Mac 예시)
plt.rc('font', family='AppleGothic')
plt.rcParams['axes.unicode_minus'] = False
```

### 1.2 주요 특징
*   **Pandas DataFrame 친화적**: DataFrame의 컬럼명을 그대로 사용하여 그래프를 그릴 수 있습니다.
*   **세련된 디자인**: 기본 스타일이 Matplotlib보다 미려합니다.
*   **통계 기능 내장**: 회귀선, 신뢰구간 등을 자동으로 계산하여 표시해 줍니다.

> **Tip**: Seaborn은 **Pandas DataFrame**과 함께 사용할 때 가장 강력합니다. 데이터 전처리가 필요하다면 **[15. python_popular_libraries.md](15.%20python_popular_libraries.md)**의 Pandas 섹션을 참고하여 데이터를 알맞은 형태로 가공하세요.

### 1.3 주요 그래프 문법 요약

자주 사용되는 Seaborn 그래프의 문법과 예제입니다.

| 그래프 종류 | 함수 | 용도 | 예제 코드 |
| :--- | :--- | :--- | :--- |
| **산점도** | `scatterplot` | 두 변수 간의 상관관계 | `sns.scatterplot(data=df, x='x', y='y', hue='group')` |
| **선 그래프** | `lineplot` | 시간/순서에 따른 추세 | `sns.lineplot(data=df, x='time', y='value')` |
| **막대 그래프** | `barplot` | 범주별 평균 비교 | `sns.barplot(data=df, x='category', y='value')` |
| **빈도 그래프** | `countplot` | 범주별 개수 확인 | `sns.countplot(data=df, x='category')` |
| **박스 플롯** | `boxplot` | 데이터 분포 및 이상치 | `sns.boxplot(data=df, x='category', y='value')` |
| **히스토그램** | `histplot` | 데이터 분포 형태 | `sns.histplot(data=df, x='value', kde=True)` |
| **히트맵** | `heatmap` | 변수 간 상관계수 시각화 | `sns.heatmap(df.corr(), annot=True)` |

#### 1.3.1 관계형 그래프 (Relational Plots)
```python
# 산점도 (Scatter Plot)
# hue: 색상으로 그룹 구분, style: 마커 모양으로 그룹 구분
sns.scatterplot(data=df, x='total_bill', y='tip', hue='sex', style='time')

# 선 그래프 (Line Plot)
# 오차 범위(ci)를 그림자로 표시함 (기본값)
sns.lineplot(data=df, x='year', y='passengers', hue='class')
```

#### 1.3.2 카테고리형 그래프 (Categorical Plots)
```python
# 막대 그래프 (Bar Plot)
# estimator: 기본값은 평균(mean), 합계(sum) 등으로 변경 가능
sns.barplot(data=df, x='day', y='total_bill', hue='sex', estimator=sum)

# 빈도 그래프 (Count Plot)
# x축이나 y축 중 하나만 지정 (개수를 세므로)
sns.countplot(data=df, x='day', hue='smoker')

# 박스 플롯 (Box Plot)
sns.boxplot(data=df, x='day', y='total_bill')
```

#### 1.3.3 분포형 및 매트릭스 그래프
```python
# 히스토그램 (Hist Plot)
# bins: 계급 구간 개수, kde: 밀도 곡선 표시 여부
sns.histplot(data=df, x='total_bill', bins=20, kde=True)

# 히트맵 (Heatmap)
# annot: 숫자 표시, cmap: 색상 테마, fmt: 소수점 형식
sns.heatmap(df.corr(), annot=True, cmap='coolwarm', fmt='.2f')
```

## 2. Folium: 지도 시각화

**Folium**은 Python 데이터를 Leaflet.js 라이브러리를 사용하여 인터랙티브한 지도로 시각화해주는 도구입니다. 웹 브라우저에서 확대/축소가 가능한 지도를 생성할 수 있습니다.

### 2.1 설치 및 임포트
```python
# 설치 (터미널)
# pip install folium

import folium
```

### 2.2 기본 지도 생성
`folium.Map` 객체를 생성하여 지도를 띄웁니다.
```python
# 위도, 경도 설정 (예: 서울 시청)
center = [37.5665, 126.9780]

# 지도 생성 (zoom_start: 초기 확대 레벨)
m = folium.Map(location=center, zoom_start=12)

# 지도 보기 (Jupyter Notebook)
m
```
*   **Tileset**: `tiles` 파라미터로 지도 스타일 변경 가능 ('OpenStreetMap', 'CartoDB positron' 등).

### 2.3 주요 기능 문법 요약

Folium에서 자주 사용하는 기능들을 정리했습니다.

| 기능 | 코드 패턴 | 설명 |
| :--- | :--- | :--- |
| **지도 생성** | `folium.Map(location=[위도, 경도], zoom_start=15)` | 기본 지도 객체 생성 |
| **마커 추가** | `folium.Marker([위도, 경도], popup='내용').add_to(m)` | 특정 위치에 핀 표시 |
| **원형 마커** | `folium.CircleMarker([위도, 경도], radius=10).add_to(m)` | 반경을 가진 원 표시 |
| **단계구분도** | `folium.Choropleth(geo_data=..., data=...).add_to(m)` | 지역별 데이터 색상 시각화 |
| **저장** | `m.save('map.html')` | HTML 파일로 내보내기 |

#### 2.3.1 마커 추가 (Markers)
```python
# 기본 마커 (Marker)
folium.Marker(
    location=[37.5665, 126.9780],
    popup='<b>서울 시청</b>',  # HTML 태그 사용 가능
    tooltip='클릭해서 정보 보기',
    icon=folium.Icon(color='blue', icon='info-sign')
).add_to(m)

# 원형 마커 (CircleMarker)
folium.CircleMarker(
    location=[37.5665, 126.9780],
    radius=20,          # 원의 크기
    color='#3186cc',    # 선 색상 (Hex Code 가능)
    fill=True,
    fill_color='#3186cc' # 채우기 색상
).add_to(m)
```

#### 2.3.2 단계구분도 (Choropleth Maps)
행정구역과 같은 영역별로 데이터의 크기를 색상으로 표현합니다.

```python
folium.Choropleth(
    geo_data='seoul_municipalities.json', # 지도 데이터 (GeoJSON)
    data=df,                              # 통계 데이터 (DataFrame)
    columns=['구이름', '인구수'],           # [매핑할 키 컬럼, 값 컬럼]
    key_on='feature.properties.name',     # GeoJSON과 매핑할 키
    fill_color='YlGn',                    # 색상 팔레트 (Yellow-Green)
    fill_opacity=0.7,
    line_opacity=0.2,
    legend_name='인구수'
).add_to(m)
```

### 2.5 저장하기
생성된 지도를 HTML 파일로 저장할 수 있습니다.
```python
m.save('my_map.html')
```
