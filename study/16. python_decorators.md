## 1. 데코레이터 기본 개념

데코레이터는 함수나 클래스를 수정하지 않고도 기능을 추가하거나 변경할 수 있게 해주는 파이썬의 강력한 기능입니다.

### 1.1 데코레이터란?

데코레이터는 다른 함수를 감싸는 함수로, 원본 함수의 동작을 확장하거나 수정합니다.

```python
def my_decorator(func):
    """데코레이터 함수"""
    def wrapper():
        print("함수 실행 전")
        func()
        print("함수 실행 후")
    return wrapper

@my_decorator
def say_hello():
    print("안녕하세요!")

say_hello()
# 출력:
# 함수 실행 전
# 안녕하세요!
# 함수 실행 후
```

### 1.2 데코레이터의 동작 원리

데코레이터는 사실상 다음 코드와 동일합니다:

```python
def say_hello():
    print("안녕하세요!")

# 데코레이터 사용
@my_decorator
def say_hello():
    print("안녕하세요!")

# 위 코드는 다음과 동일합니다:
say_hello = my_decorator(say_hello)
```

## 2. 함수 데코레이터

### 2.1 기본 함수 데코레이터

```python
def timer_decorator(func):
    """함수 실행 시간을 측정하는 데코레이터"""
    import time
    
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        print(f"{func.__name__} 실행 시간: {end_time - start_time:.4f}초")
        return result
    return wrapper

@timer_decorator
def slow_function():
    import time
    time.sleep(1)
    return "완료"

result = slow_function()
# 출력: slow_function 실행 시간: 1.0001초
```

### 2.2 함수 메타데이터 보존 (functools.wraps)

데코레이터를 사용하면 원본 함수의 메타데이터가 손실될 수 있습니다. `functools.wraps`를 사용하여 보존할 수 있습니다.

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)  # 원본 함수의 메타데이터 보존
    def wrapper(*args, **kwargs):
        print(f"{func.__name__} 호출됨")
        return func(*args, **kwargs)
    return wrapper

@my_decorator
def example_function():
    """예제 함수입니다"""
    pass

print(example_function.__name__)  # example_function (wraps 없으면 wrapper)
print(example_function.__doc__)   # 예제 함수입니다 (wraps 없으면 None)
```

### 2.3 인자를 받는 함수 데코레이터

```python
from functools import wraps

def log_calls(func):
    """함수 호출을 로깅하는 데코레이터"""
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"[LOG] {func.__name__} 호출됨 - 인자: {args}, {kwargs}")
        result = func(*args, **kwargs)
        print(f"[LOG] {func.__name__} 완료 - 결과: {result}")
        return result
    return wrapper

@log_calls
def add(a, b):
    return a + b

@log_calls
def greet(name, greeting="안녕하세요"):
    return f"{greeting}, {name}님!"

add(3, 5)
# 출력:
# [LOG] add 호출됨 - 인자: (3, 5), {}
# [LOG] add 완료 - 결과: 8

greet("홍길동", greeting="반갑습니다")
# 출력:
# [LOG] greet 호출됨 - 인자: ('홍길동',), {'greeting': '반갑습니다'}
# [LOG] greet 완료 - 결과: 반갑습니다, 홍길동님!
```

## 3. 클래스 데코레이터

클래스에도 데코레이터를 적용할 수 있습니다.

### 3.1 기본 클래스 데코레이터

```python
def add_method(cls):
    """클래스에 메서드를 추가하는 데코레이터"""
    def new_method(self):
        return f"{self.__class__.__name__}의 새 메서드"
    
    cls.new_method = new_method
    return cls

@add_method
class MyClass:
    def __init__(self, value):
        self.value = value

obj = MyClass(10)
print(obj.new_method())  # MyClass의 새 메서드
```

### 3.2 싱글톤 패턴 데코레이터

```python
def singleton(cls):
    """싱글톤 패턴을 구현하는 데코레이터"""
    instances = {}
    
    def get_instance(*args, **kwargs):
        if cls not in instances:
            instances[cls] = cls(*args, **kwargs)
        return instances[cls]
    
    return get_instance

@singleton
class Database:
    def __init__(self):
        print("데이터베이스 연결 생성")
        self.data = []

db1 = Database()  # 데이터베이스 연결 생성
db2 = Database()   # 출력 없음 (이미 생성됨)
print(db1 is db2)  # True (같은 인스턴스)
```

## 4. 내장 데코레이터

파이썬에는 여러 유용한 내장 데코레이터가 있습니다.

### 4.1 @property

```python
class Temperature:
    def __init__(self, celsius):
        self._celsius = celsius
    
    @property
    def celsius(self):
        """섭씨 온도"""
        return self._celsius
    
    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("절대 영도보다 낮을 수 없습니다")
        self._celsius = value
    
    @property
    def fahrenheit(self):
        """화씨 온도 (읽기 전용)"""
        return self._celsius * 9/5 + 32

temp = Temperature(25)
print(temp.celsius)      # 25
print(temp.fahrenheit)   # 77.0
temp.celsius = 30
print(temp.fahrenheit)   # 86.0
```

### 4.2 @staticmethod

```python
class MathHelper:
    @staticmethod
    def add(a, b):
        return a + b
    
    @staticmethod
    def multiply(a, b):
        return a * b

result = MathHelper.add(3, 5)  # 8
```

### 4.5 @functools.lru_cache

```python
from functools import lru_cache

@lru_cache(maxsize=128)
def fibonacci(n):
    """피보나치 수열 계산 (메모이제이션)"""
    if n < 2:
        return n

# 첫 번째 호출: 계산 수행

# 두 번째 호출: 캐시에서 반환 (빠름)

```

def bold(func):

## 6. 파라미터를 받는 데코레이터

데코레이터 자체가 파라미터를 받을 수 있습니다.

### 6.1 기본 구조

```python
def repeat(times):
    """함수를 여러 번 실행하는 데코레이터"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(times=3)
def say_hello():
    print("안녕하세요!")

say_hello()
# 출력:
# 안녕하세요!
# 안녕하세요!
# 안녕하세요!
```

### 6.2 선택적 파라미터 데코레이터

```python
def retry(max_attempts=3, delay=1):
    """실패 시 재시도하는 데코레이터"""
    import time
    
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(max_attempts):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == max_attempts - 1:
                        raise
                    print(f"시도 {attempt + 1} 실패, {delay}초 후 재시도...")
                    time.sleep(delay)
        return wrapper
    return decorator

@retry(max_attempts=3, delay=2)
def unreliable_function():
    import random
    if random.random() < 0.7:
        raise ValueError("임의 오류")
    return "성공!"
```

## 7. 데코레이터 팩토리

더 복잡한 데코레이터를 만들기 위한 패턴입니다.

### 7.1 데코레이터 팩토리 패턴

```python
def validate_types(**expected_types):
    """타입 검증 데코레이터 팩토리"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            # 위치 인자 검증
            param_names = list(func.__code__.co_varnames[:func.__code__.co_argcount])
            for i, (arg, param_name) in enumerate(zip(args, param_names)):
                if param_name in expected_types:
                    expected_type = expected_types[param_name]
                    if not isinstance(arg, expected_type):
                        raise TypeError(
                            f"{param_name}은(는) {expected_type.__name__} 타입이어야 합니다"
                        )
            
            # 키워드 인자 검증
            for param_name, value in kwargs.items():
                if param_name in expected_types:
                    expected_type = expected_types[param_name]
                    if not isinstance(value, expected_type):
                        raise TypeError(
                            f"{param_name}은(는) {expected_type.__name__} 타입이어야 합니다"
                        )
            
            return func(*args, **kwargs)
        return wrapper
    return decorator

@validate_types(name=str, age=int)
def create_person(name, age):
    return f"{name}님은 {age}세입니다"

print(create_person("홍길동", 25))  # ✅ 정상
# print(create_person("홍길동", "25"))  # ❌ TypeError
```

## 8. 실용적인 예제

### 8.1 실행 시간 측정 데코레이터

```python
import time
from functools import wraps

def timing_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        execution_time = end_time - start_time
        print(f"{func.__name__} 실행 시간: {execution_time:.6f}초")
        return result
    return wrapper

@timing_decorator
def slow_function():
    time.sleep(0.1)
    return "완료"

slow_function()
```

logging.basicConfig(level=logging.INFO)

from functools import wraps

def require_permission(permission):

### 8.4 메모이제이션 데코레이터

```python
from functools import wraps

def memoize(func):
    """간단한 메모이제이션 데코레이터"""
    cache = {}
    
    @wraps(func)
    def wrapper(*args, **kwargs):
        # 키 생성 (튜플은 해시 가능하지만 딕셔너리는 아님)
        key = str(args) + str(sorted(kwargs.items()))
        
        if key not in cache:
            cache[key] = func(*args, **kwargs)
        
        return cache[key]
    return wrapper

@memoize
def expensive_function(n):
    print(f"계산 중: {n}")
    return n * n

print(expensive_function(5))  # 계산 중: 5, 25
print(expensive_function(5))  # 25 (캐시에서 반환)
```

### 8.5 재시도 데코레이터

```python
import time
from functools import wraps

def retry_on_failure(max_retries=3, delay=1, backoff=2):
    """실패 시 재시도하는 데코레이터"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            current_delay = delay
            for attempt in range(max_retries):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt == max_retries - 1:
                        raise
                    print(f"시도 {attempt + 1} 실패: {e}. {current_delay}초 후 재시도...")
                    time.sleep(current_delay)
                    current_delay *= backoff
        return wrapper
    return decorator

@retry_on_failure(max_retries=3, delay=1, backoff=2)
def unreliable_api_call():
    import random
    if random.random() < 0.7:
        raise ConnectionError("연결 실패")
    return "성공!"
```

### 8.6 타입 검증 데코레이터

```python
from functools import wraps

def type_check(**expected_types):
    """런타임 타입 검증 데코레이터"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            # 함수 시그니처 가져오기
            import inspect
            sig = inspect.signature(func)
            bound_args = sig.bind(*args, **kwargs)
            bound_args.apply_defaults()
            
            # 타입 검증
            for param_name, value in bound_args.arguments.items():
                if param_name in expected_types:
                    expected_type = expected_types[param_name]
                    if not isinstance(value, expected_type):
                        raise TypeError(
                            f"{param_name}은(는) {expected_type.__name__} 타입이어야 합니다. "
                            f"받은 타입: {type(value).__name__}"
                        )
            
            return func(*args, **kwargs)
        return wrapper
    return decorator

@type_check(name=str, age=int, salary=float)
def create_employee(name, age, salary):
    return f"{name}님, {age}세, 급여: {salary}"

print(create_employee("홍길동", 30, 50000.0))  # ✅ 정상
# print(create_employee("홍길동", "30", 50000.0))  # ❌ TypeError
```

## 9. 주의사항

### 9.1 메타데이터 보존

```python
# ❌ 나쁜 예: 메타데이터 손실

    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@bad_decorator
def example():
    """예제 함수"""
    pass

# ✅ 좋은 예: functools.wraps 사용
from functools import wraps

def good_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper

@good_decorator
def example():
    """예제 함수"""
    pass

print(example.__name__)  # example
print(example.__doc__)   # 예제 함수
```

### 9.3 클로저 변수 주의

```python
# ❌ 나쁜 예: 루프 변수 캡처 문제
decorators = []
for i in range(3):
    def decorator(func):
        def wrapper():
            print(f"데코레이터 {i}")  # 항상 2 출력
            return func()
        return wrapper
    decorators.append(decorator)

# ✅ 좋은 예: 기본 인자 사용
decorators = []
for i in range(3):
    def make_decorator(num):
        def decorator(func):
            def wrapper():
                print(f"데코레이터 {num}")
                return func()
            return wrapper
        return decorator
    decorators.append(make_decorator(i))
```

### 9.4 데코레이터와 디버깅

```python
from functools import wraps
import inspect

def debug_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(f"함수: {func.__name__}")
        print(f"인자: {args}, {kwargs}")
        print(f"소스 파일: {inspect.getfile(func)}")
        result = func(*args, **kwargs)
        print(f"반환값: {result}")
        return result
    return wrapper

@debug_decorator
def example(x, y):
    return x + y

example(3, 5)
```

## 10. 요약

### 핵심 개념

1. **데코레이터**: 함수나 클래스를 수정하지 않고 기능을 추가하는 패턴
2. **함수 데코레이터**: 함수를 감싸서 기능을 확장
3. **클래스 데코레이터**: 클래스에 기능을 추가하거나 수정
4. **데코레이터 체이닝**: 여러 데코레이터를 순차적으로 적용

### 주요 데코레이터

- `@property`: 프로퍼티 접근 제어
- `@staticmethod`: 정적 메서드
- `@classmethod`: 클래스 메서드
- `@abstractmethod`: 추상 메서드
- `@functools.wraps`: 메타데이터 보존
- `@functools.lru_cache`: 메모이제이션

### 모범 사례

- ✅ `functools.wraps` 사용하여 메타데이터 보존
- ✅ 데코레이터 순서 이해하기
- ✅ 클로저 변수 캡처 주의
- ✅ 재사용 가능한 데코레이터 작성
- ✅ 명확한 이름과 문서화
