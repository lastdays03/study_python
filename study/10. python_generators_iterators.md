## 1. 이터러블과 이터레이터

### 1.1 이터러블(Iterable)

**이터러블**은 반복 가능한 객체입니다. `for` 루프에서 사용할 수 있습니다.

```python
# 이터러블 예시
numbers = [1, 2, 3, 4, 5]  # 리스트
text = "hello"              # 문자열
numbers_range = range(5)    # range

# 모두 for 루프에서 사용 가능
for item in numbers:
    print(item)
```

### 1.2 이터레이터(Iterator)

**이터레이터**는 `next()` 함수로 다음 값을 가져올 수 있는 객체입니다.

```python
# 이터레이터 생성
numbers = [1, 2, 3]
iterator = iter(numbers)

# next()로 값 가져오기
print(next(iterator))  # 1
print(next(iterator))  # 2
print(next(iterator))  # 3
# print(next(iterator))  # StopIteration 예외 발생
```

### 1.3 이터러블 vs 이터레이터

```python
# 이터러블
numbers = [1, 2, 3]
print(iter(numbers))  # <list_iterator object>

# 이터레이터는 iter()를 호출하면 자기 자신 반환
iterator = iter(numbers)
print(iter(iterator) is iterator)  # True
```

## 2. 제너레이터란?

### 2.1 제너레이터의 개념

**제너레이터(Generator)**는 이터레이터를 생성하는 함수입니다. 메모리를 효율적으로 사용합니다.

```python
# 제너레이터 함수
def count_up_to(max):
    count = 1
    while count <= max:
        yield count
        count += 1

# 사용
counter = count_up_to(5)
for num in counter:
    print(num)  # 1, 2, 3, 4, 5
```

### 2.2 제너레이터의 장점

- **메모리 효율**: 한 번에 하나의 값만 생성
- **지연 평가**: 필요할 때만 값 생성
- **무한 시퀀스**: 무한한 데이터 생성 가능

## 3. 제너레이터 함수

### 3.1 yield 키워드

```python
def simple_generator():
    yield 1
    yield 2
    yield 3

gen = simple_generator()
print(next(gen))  # 1
print(next(gen))  # 2
print(next(gen))  # 3
```

### 3.2 제너레이터 함수 예제

```python
def fibonacci(n):
    """피보나치 수열 생성"""
    a, b = 0, 1
    count = 0
    while count < n:
        yield a
        a, b = b, a + b
        count += 1

# 사용
for num in fibonacci(10):
    print(num)
```

### 3.3 제너레이터와 return

```python
def generator_with_return():
    yield 1
    yield 2
    return "완료"  # 제너레이터 종료 (값은 반환되지 않음)
    yield 3  # 실행되지 않음

gen = generator_with_return()
print(list(gen))  # [1, 2]
```

## 4. 제너레이터 표현식

### 4.1 기본 사용법

```python
# 리스트 컴프리헨션
squares_list = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]

# 제너레이터 표현식
squares_gen = (x**2 for x in range(5))  # <generator object>
print(list(squares_gen))  # [0, 1, 4, 9, 16]
```

### 4.2 메모리 효율성 비교

```python
# 리스트 컴프리헨션 - 모든 값을 메모리에 저장
big_list = [x**2 for x in range(1000000)]  # 메모리 많이 사용

# 제너레이터 표현식 - 필요할 때만 생성
big_gen = (x**2 for x in range(1000000))  # 메모리 효율적
```

### 4.3 제너레이터 표현식 예제

```python
# 조건부 제너레이터
evens = (x for x in range(10) if x % 2 == 0)
print(list(evens))  # [0, 2, 4, 6, 8]

# 중첩 제너레이터
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flattened = (item for row in matrix for item in row)
print(list(flattened))  # [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## 5. 제너레이터 메서드

### 5.1 send() 메서드

```python
def generator_with_send():
    value = yield
    while True:
        value = yield value * 2

gen = generator_with_send()
next(gen)  # 제너레이터 시작
print(gen.send(5))   # 10
print(gen.send(10))  # 20
```

### 5.2 throw() 메서드

```python
def generator_with_throw():
    try:
        yield 1
        yield 2
    except ValueError:
        yield "에러 처리됨"

gen = generator_with_throw()
print(next(gen))  # 1
print(gen.throw(ValueError))  # "에러 처리됨"
```

### 5.3 close() 메서드

```python
def generator_with_close():
    try:
        yield 1
        yield 2
        yield 3
    except GeneratorExit:
        print("제너레이터 종료")

gen = generator_with_close()
print(next(gen))  # 1
gen.close()  # 제너레이터 종료
```

## 6. 이터레이터 프로토콜

### 6.1 커스텀 이터레이터 클래스

```python
class CountDown:
    def __init__(self, start):
        self.start = start
    
    def __iter__(self):
        return self
    
    def __next__(self):
        if self.start <= 0:
            raise StopIteration
        self.start -= 1
        return self.start + 1

# 사용
counter = CountDown(5)
for num in counter:
    print(num)  # 5, 4, 3, 2, 1
```

## 7. 제너레이터 vs 리스트

### 7.1 성능 비교

```python
import sys

# 리스트 컴프리헨션
list_comp = [x**2 for x in range(1000)]
print(sys.getsizeof(list_comp))  # 큰 메모리 사용

# 제너레이터 표현식
gen_expr = (x**2 for x in range(1000))
print(sys.getsizeof(gen_expr))  # 작은 메모리 사용
```

### 7.2 언제 사용할까?

**리스트 컴프리헨션 사용:**
- 모든 값을 한 번에 필요할 때
- 인덱싱이나 슬라이싱이 필요할 때
- 여러 번 반복해야 할 때

**제너레이터 사용:**
- 메모리가 제한적일 때
- 큰 데이터셋 처리
- 한 번만 순회할 때
- 무한 시퀀스 생성

## 8. 실전 예제

### 8.1 파일 읽기

```python
def read_large_file(filename):
    """큰 파일을 한 줄씩 읽기"""
    with open(filename, 'r') as f:
        for line in f:
            yield line.strip()

# 사용
for line in read_large_file('large_file.txt'):
    process(line)
```

### 8.2 배치 처리

```python
def batch_process(items, batch_size=10):
    """항목을 배치로 나누기"""
    for i in range(0, len(items), batch_size):
        yield items[i:i + batch_size]

items = list(range(100))
for batch in batch_process(items, batch_size=20):
    print(batch)
```

### 8.3 무한 시퀀스

```python
def infinite_counter(start=0):
    """무한 카운터"""
    while True:
        yield start
        start += 1

counter = infinite_counter(10)
for i, num in enumerate(counter):
    if i >= 5:
        break
    print(num)  # 10, 11, 12, 13, 14
```

### 8.4 파이프라인 패턴

```python
def numbers():
    for i in range(10):
        yield i

def square(nums):
    for num in nums:
        yield num ** 2

def filter_even(nums):
    for num in nums:
        if num % 2 == 0:
            yield num

# 파이프라인 연결
pipeline = filter_even(square(numbers()))
print(list(pipeline))  # [0, 4, 16, 36, 64]
```

## 9. 주의사항

### 9.1 제너레이터는 한 번만 사용 가능

```python
gen = (x for x in range(5))
print(list(gen))  # [0, 1, 2, 3, 4]
print(list(gen))  # [] - 이미 소비됨!
```

### 9.2 제너레이터 재생성

```python
# 제너레이터 함수를 다시 호출
def numbers():
    for i in range(5):
        yield i

gen1 = numbers()
gen2 = numbers()  # 새로운 제너레이터
print(list(gen1))  # [0, 1, 2, 3, 4]
print(list(gen2))  # [0, 1, 2, 3, 4]
```

## 10. 요약

### 핵심 개념

1. **이터러블**: 반복 가능한 객체
2. **이터레이터**: `next()`로 값을 가져오는 객체
3. **제너레이터**: `yield`를 사용하는 함수
4. **제너레이터 표현식**: 괄호로 만드는 제너레이터

### 주요 특징

- ✅ 메모리 효율적
- ✅ 지연 평가
- ✅ 무한 시퀀스 생성 가능
- ⚠️ 한 번만 사용 가능

### 사용 시기

- **제너레이터**: 큰 데이터, 메모리 제한, 한 번만 순회
- **리스트**: 모든 값 필요, 인덱싱, 여러 번 반복
