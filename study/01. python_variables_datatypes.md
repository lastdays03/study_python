## 1. 변수(Variable) 기본 개념

### 1.1 변수란?

**변수**는 데이터를 저장하는 메모리 공간에 붙인 이름입니다. 파이썬에서는 변수에 값을 할당하면 자동으로 타입이 결정됩니다.

```python
# 변수 선언 및 할당
name = "홍길동"
age = 25
height = 175.5
is_student = True
```

### 1.2 변수 명명 규칙

#### 기본 규칙
- 영문자, 숫자, 언더스코어(`_`)만 사용 가능
- 숫자로 시작할 수 없음
- 대소문자를 구분함
- 예약어(keyword)는 사용할 수 없음

```python
# 올바른 변수명
name = "홍길동"
user_name = "홍길동"
userName = "홍길동"
user_name_1 = "홍길동"
_name = "홍길동"

# 잘못된 변수명
1name = "홍길동"      # 숫자로 시작
user-name = "홍길동"  # 하이픈 사용 불가
user name = "홍길동"  # 공백 사용 불가
class = "홍길동"      # 예약어 사용 불가
```

#### 명명 규칙 (Naming Conventions)

**스네이크 케이스 (snake_case)** - 권장
```python
user_name = "홍길동"
total_count = 100
is_valid = True
```

**캐멀 케이스 (camelCase)** - 선택적
```python
userName = "홍길동"
totalCount = 100
isValid = True
```

**파스칼 케이스 (PascalCase)** - 클래스명에 사용
```python
UserName = "홍길동"  # 변수에는 권장하지 않음
```

### 1.3 변수 할당

#### 단일 할당
```python
x = 10
y = 20
name = "홍길동"
```

#### 다중 할당
```python
# 여러 변수에 같은 값 할당
x = y = z = 0

# 여러 변수에 다른 값 할당
x, y, z = 1, 2, 3
name, age = "홍길동", 25
```

#### 변수 교환
```python
a = 10
b = 20

# 임시 변수 없이 교환
a, b = b, a
print(a)  # 20
print(b)  # 10
```

### 1.4 변수 타입 확인

```python
x = 10
name = "홍길동"

print(type(x))      # <class 'int'>
print(type(name))   # <class 'str'>
print(isinstance(x, int))  # True
```

### 1.5 변수 삭제

```python
x = 10
del x
# print(x)  # NameError: name 'x' is not defined
```

## 2. 기본 자료형 (Basic Data Types)

### 2.1 숫자형 (Numeric Types)

#### 정수 (int)
```python
# 정수
x = 10
y = -5
z = 0

# 큰 정수도 자동 처리
big_number = 12345678901234567890

# 진법 표현
binary = 0b1010      # 2진법 (10)
octal = 0o755         # 8진법 (493)
hexadecimal = 0xFF    # 16진법 (255)
```

#### 실수 (float)
```python
# 실수
x = 3.14
y = -2.5
z = 0.0

# 과학적 표기법
scientific = 1.23e4   # 12300.0
small = 1.23e-4       # 0.000123
```

#### 복소수 (complex)
```python
# 복소수
z = 3 + 4j
z = complex(3, 4)     # 3 + 4j

print(z.real)         # 3.0 (실수부)
print(z.imag)         # 4.0 (허수부)
```

### 2.2 불린형 (bool)

```python
# 불린 값
is_true = True
is_false = False

# 비교 연산 결과
result = 10 > 5       # True
result = 10 < 5      # False

# 타입 변환
bool(1)              # True
bool(0)              # False
bool("")             # False
bool("hello")        # True
bool([])             # False
bool([1, 2])         # True
```

### 2.3 문자열 (str)

#### 문자열 생성
```python
# 작은따옴표
name = '홍길동'

# 큰따옴표
name = "홍길동"

# 삼중 따옴표 (여러 줄)
text = """여러 줄
문자열
입니다"""

# 삼중 따옴표 (한 줄)
text = '''한 줄 문자열'''
```

#### 문자열 연산
```python
# 연결
greeting = "Hello" + " " + "World"  # "Hello World"

# 반복
stars = "*" * 5  # "*****"

# 인덱싱
text = "Python"
print(text[0])    # 'P'
print(text[-1])   # 'n' (뒤에서 첫 번째)

# 슬라이싱
print(text[0:3])  # 'Pyt'
print(text[:3])    # 'Pyt'
print(text[3:])    # 'hon'
print(text[:])     # 'Python'
print(text[::-1])  # 'nohtyP' (역순)
```

#### 문자열 메서드
```python
text = "  Hello World  "

# 대소문자 변환
text.upper()        # "  HELLO WORLD  "
text.lower()        # "  hello world  "
text.title()        # "  Hello World  "
text.capitalize()  # "  hello world  "

# 공백 제거
text.strip()        # "Hello World"
text.lstrip()       # "Hello World  "
text.rstrip()       # "  Hello World"

# 검색 및 치환
text.find("World")  # 9
text.replace("World", "Python")  # "  Hello Python  "

# 분할 및 결합
"apple,banana,cherry".split(",")  # ['apple', 'banana', 'cherry']
", ".join(['apple', 'banana'])    # "apple, banana"
```

#### f-string (포맷팅)
```python
name = "홍길동"
age = 25

# f-string (Python 3.6+)
message = f"이름: {name}, 나이: {age}"

# 표현식 사용
result = f"{name}은 {age + 1}살이 됩니다"

# 포맷 지정
pi = 3.14159
print(f"원주율: {pi:.2f}")  # "원주율: 3.14"
```

## 3. 컬렉션 자료형 (Collection Types)

### 3.1 리스트 (list)

#### 리스트 생성
```python
# 빈 리스트
empty_list = []
empty_list = list()

# 리스트 생성
numbers = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True]
nested = [[1, 2], [3, 4], [5, 6]]
```

#### 리스트 연산
```python
# 인덱싱
numbers = [1, 2, 3, 4, 5]
print(numbers[0])    # 1
print(numbers[-1])   # 5

# 슬라이싱
print(numbers[1:3])  # [2, 3]
print(numbers[:3])   # [1, 2, 3]
print(numbers[3:])   # [4, 5]

# 연결
list1 = [1, 2]
list2 = [3, 4]
combined = list1 + list2  # [1, 2, 3, 4]

# 반복
repeated = [1, 2] * 3  # [1, 2, 1, 2, 1, 2]
```

#### 리스트 메서드
```python
numbers = [1, 2, 3]

# 추가
numbers.append(4)           # [1, 2, 3, 4]
numbers.insert(0, 0)        # [0, 1, 2, 3, 4]
numbers.extend([5, 6])      # [0, 1, 2, 3, 4, 5, 6]

# 제거
numbers.remove(0)           # [1, 2, 3, 4, 5, 6]
popped = numbers.pop()      # 6, numbers = [1, 2, 3, 4, 5]
popped = numbers.pop(0)     # 1, numbers = [2, 3, 4, 5]

# 검색
index = numbers.index(3)    # 1
count = numbers.count(3)    # 1

# 정렬
numbers.sort()              # 오름차순 정렬
numbers.sort(reverse=True)  # 내림차순 정렬
sorted_numbers = sorted(numbers)  # 새 리스트 반환

# 뒤집기
numbers.reverse()
```

### 3.3 딕셔너리 (dict)

#### 딕셔너리 생성
```python
# 빈 딕셔너리
empty_dict = {}
empty_dict = dict()

# 딕셔너리 생성
person = {
    'name': '홍길동',
    'age': 25,
    'city': '서울'

# dict() 생성자 사용
person = dict(name='홍길동', age=25, city='서울')
```

#### 딕셔너리 접근
```python
person = {'name': '홍길동', 'age': 25}

# 값 접근
print(person['name'])        # '홍길동'
print(person.get('age'))    # 25
print(person.get('city', '서울'))  # 기본값 '서울'

# 값 수정
person['age'] = 26

# 항목 추가
person['city'] = '부산'

# 항목 제거
del person['city']
city = person.pop('city', '서울')  # 기본값과 함께 제거
```

#### 딕셔너리 메서드
```python
person = {'name': '홍길동', 'age': 25}

# 키, 값, 항목
keys = person.keys()         # dict_keys(['name', 'age'])
values = person.values()    # dict_values(['홍길동', 25])
items = person.items()      # dict_items([('name', '홍길동'), ('age', 25)])

# 업데이트
person.update({'age': 26, 'city': '서울'})

# 복사
person_copy = person.copy()

# 모든 항목 제거
person.clear()
```

### 3.4 집합 (set)

#### 집합 생성
```python
# 빈 집합
empty_set = set()  # {}는 딕셔너리이므로 주의!

# 집합 생성
numbers = {1, 2, 3, 4, 5}
mixed = {1, "hello", 3.14}

# 중복 제거
unique = set([1, 2, 2, 3, 3, 4])  # {1, 2, 3, 4}
```

#### 집합 연산
```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

# 합집합
union = set1 | set2        # {1, 2, 3, 4, 5}
union = set1.union(set2)

# 교집합
intersection = set1 & set2  # {3}
intersection = set1.intersection(set2)

# 차집합
difference = set1 - set2    # {1, 2}
difference = set1.difference(set2)

# 대칭차집합
symmetric = set1 ^ set2     # {1, 2, 4, 5}
symmetric = set1.symmetric_difference(set2)
```

#### 집합 메서드
```python
numbers = {1, 2, 3}

# 추가
numbers.add(4)              # {1, 2, 3, 4}
numbers.update([5, 6])      # {1, 2, 3, 4, 5, 6}

# 제거
numbers.remove(1)           # {2, 3, 4, 5, 6}
numbers.discard(10)         # 없어도 에러 없음
popped = numbers.pop()      # 임의의 요소 제거

# 검색
print(2 in numbers)         # True
print(10 in numbers)        # False
```

## 4. 타입 변환 (Type Conversion)

### 4.1 명시적 타입 변환

```python
# 정수 변환
int("123")          # 123
int(3.14)           # 3 (소수점 버림)
int(True)           # 1
int(False)           # 0

# 실수 변환
float("3.14")       # 3.14
float(10)           # 10.0
float(True)         # 1.0

# 문자열 변환
str(123)            # "123"
str(3.14)           # "3.14"
str(True)           # "True"

# 불린 변환
bool(1)             # True
bool(0)             # False
bool("")            # False
bool("hello")       # True
bool([])            # False
bool([1, 2])        # True

# 리스트 변환
list("hello")       # ['h', 'e', 'l', 'l', 'o']
list((1, 2, 3))     # [1, 2, 3]
list({1, 2, 3})     # [1, 2, 3]

# 튜플 변환
tuple([1, 2, 3])    # (1, 2, 3)
tuple("hello")      # ('h', 'e', 'l', 'l', 'o')

# 집합 변환
set([1, 2, 2, 3])   # {1, 2, 3}
set("hello")        # {'h', 'e', 'l', 'o'}
```

### 4.2 자동 타입 변환

```python
# 산술 연산 시
result = 10 + 3.14  # 13.14 (int → float)

# 비교 연산 시
print(10 == 10.0)   # True (자동 변환)
```

## 5. 가변성 (Mutability)

### 5.1 불변 타입 (Immutable)

수정할 수 없는 타입입니다.

```python
# 불변 타입
x = 10
x = 20  # 새로운 객체 생성 (기존 객체 수정 아님)

text = "hello"
# text[0] = 'H'  # TypeError 발생

numbers = (1, 2, 3)
# numbers[0] = 10  # TypeError 발생
```

**불변 타입**: `int`, `float`, `str`, `tuple`, `bool`, `frozenset`

### 5.2 가변 타입 (Mutable)

수정할 수 있는 타입입니다.

```python
# 가변 타입
numbers = [1, 2, 3]
numbers[0] = 10  # 수정 가능

person = {'name': '홍길동'}
person['age'] = 25  # 수정 가능

numbers_set = {1, 2, 3}
numbers_set.add(4)  # 수정 가능
```

**가변 타입**: `list`, `dict`, `set`

### 5.3 가변성과 참조

```python
# 리스트 (가변)
list1 = [1, 2, 3]
list2 = list1  # 같은 객체 참조
list2.append(4)
print(list1)  # [1, 2, 3, 4] - list1도 변경됨!

# 복사본 생성
list3 = list1.copy()  # 또는 list1[:]
list3.append(5)
print(list1)  # [1, 2, 3, 4] - list1은 변경 안 됨

# 튜플 (불변)
tuple1 = (1, 2, 3)
tuple2 = tuple1  # 같은 객체 참조
# tuple2[0] = 10  # 불가능 - 튜플은 불변
```

## 6. None 타입

### 6.1 None 개념

`None`은 값이 없음을 나타내는 특별한 타입입니다.

```python
# None 할당
value = None
print(value)        # None
print(type(value))  # <class 'NoneType'>

# None 확인
if value is None:
    print("값이 없습니다")

# None과 비교
print(value == None)   # True (권장하지 않음)
print(value is None)   # True (권장)
```

### 6.2 None 사용 예제

```python
def find_user(user_id):
    # 사용자를 찾지 못한 경우
    return None

user = find_user(123)
if user is None:
    print("사용자를 찾을 수 없습니다")
```

## 7. 타입 힌팅 (Type Hints)

### 7.1 기본 타입 힌팅

```python
# 변수 타입 힌팅
name: str = "홍길동"
age: int = 25
height: float = 175.5
is_student: bool = True

# 리스트 타입 힌팅
from typing import List, Dict, Tuple, Set, Optional

numbers: List[int] = [1, 2, 3]
names: List[str] = ["홍길동", "김철수"]

# 딕셔너리 타입 힌팅
person: Dict[str, any] = {'name': '홍길동', 'age': 25}
scores: Dict[str, int] = {'math': 90, 'english': 85}

# 튜플 타입 힌팅
point: Tuple[int, int] = (10, 20)
info: Tuple[str, int, bool] = ("홍길동", 25, True)

# 집합 타입 힌팅
numbers_set: Set[int] = {1, 2, 3}

# Optional (None 가능)
value: Optional[str] = None
value: Optional[int] = 10
```

### 7.2 함수 타입 힌팅

```python
def greet(name: str) -> str:
    return f"Hello, {name}"

def add(x: int, y: int) -> int:
    return x + y

def get_user(user_id: int) -> Optional[Dict[str, any]]:
    # 사용자 반환 또는 None
    return None
```

### 9.3 타입 검증 예제

```python
def process_number(value):
    if not isinstance(value, (int, float)):
        raise TypeError("숫자만 입력 가능합니다")

def process_name(name):
    if not isinstance(name, str):
        raise TypeError("문자열만 입력 가능합니다")

```

## 10. 자료형별 특징 비교

### 10.1 비교표

| 자료형 | 가변성 | 순서 | 중복 | 인덱싱 | 용도 |
|--------|--------|------|------|--------|------|
| **int** | 불변 | - | - | - | 정수 |
| **float** | 불변 | - | - | - | 실수 |
| **str** | 불변 | 있음 | 가능 | 가능 | 문자열 |
| **bool** | 불변 | - | - | - | 불린 |
| **list** | 가변 | 있음 | 가능 | 가능 | 순서 있는 컬렉션 |
| **tuple** | 불변 | 있음 | 가능 | 가능 | 불변 리스트 |
| **dict** | 가변 | 없음 | 키 불가 | 키로 접근 | 키-값 쌍 |
| **set** | 가변 | 없음 | 불가 | 불가 | 고유한 요소 |

### 10.2 선택 가이드

- **순서가 중요하고 수정이 필요**: `list`
- **순서가 중요하지만 수정 불필요**: `tuple`
- **키-값 쌍이 필요**: `dict`
- **고유한 값만 필요**: `set`
- **문자열 처리**: `str`
- **숫자 계산**: `int`, `float`

### 11.3 자료형 조합 활용

```python
# 학생 성적 관리
students = [
    {'name': '홍길동', 'scores': [90, 85, 92]},
    {'name': '김철수', 'scores': [88, 90, 87]},
    {'name': '이영희', 'scores': [95, 92, 94]}
]

# 평균 계산
for student in students:
    scores = student['scores']
    average = sum(scores) / len(scores)
    student['average'] = round(average, 2)

# 정렬
students_sorted = sorted(students, key=lambda x: x['average'], reverse=True)
```

## 12. 주의사항

### 12.1 가변 객체 참조

```python
# 주의: 같은 객체 참조
list1 = [1, 2, 3]
list2 = list1
list2.append(4)
print(list1)  # [1, 2, 3, 4] - list1도 변경됨!

# 해결: 복사본 생성
list3 = list1.copy()  # 또는 list1[:]
list3.append(5)
print(list1)  # [1, 2, 3, 4] - list1은 변경 안 됨
```

### 12.2 타입 변환 오류

```python
# 주의: 변환 실패 시 예외 발생
try:
    number = int("abc")  # ValueError
except ValueError:
    print("변환 실패")

# 안전한 변환
def safe_int(value, default=0):
    try:
        return int(value)
    except (ValueError, TypeError):
        return default
```

# 나쁜 예

## 13. 요약

### 핵심 개념

1. **변수**: 데이터를 저장하는 이름
2. **자료형**: 데이터의 타입 (int, str, list, dict 등)
3. **가변성**: 수정 가능 여부 (mutable/immutable)
4. **타입 변환**: 한 타입을 다른 타입으로 변환

### 주요 자료형

- **숫자**: `int`, `float`, `complex`
- **문자열**: `str`
- **불린**: `bool`
- **컬렉션**: `list`, `tuple`, `dict`, `set`
- **특수**: `None`, `bytes`, `range`

### 모범 사례

- ✅ 명확한 변수명 사용 (snake_case)
- ✅ 적절한 자료형 선택
- ✅ 타입 힌팅 사용 (선택)
- ✅ 가변 객체 참조 주의
- ✅ `is None` 사용 (== None 대신)

### 주의사항

- ⚠️ 가변 객체의 참조 공유
- ⚠️ 타입 변환 실패 가능성
- ⚠️ None 비교 시 `is` 사용
- ⚠️ 예약어 사용 금지
