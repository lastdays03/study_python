# 파이썬 예외처리(Exception Handling) 완전 가이드

## 1. 예외처리 기본 개념

### 1.1 예외(Exception)란?

**예외**는 프로그램 실행 중 발생하는 오류입니다. 예외가 발생하면 프로그램이 중단되지만, 예외처리를 통해 이를 처리할 수 있습니다.

```python
# 예외가 발생하는 코드
result = 10 / 0  # ZeroDivisionError 발생
```

### 1.2 예외처리가 필요한 이유

- 프로그램이 예상치 못한 상황에서도 계속 실행되도록 함
- 사용자에게 친절한 오류 메시지 제공
- 리소스 정리 (파일 닫기, 연결 종료 등)
- 로깅 및 디버깅 정보 수집

### 1.3 예외 vs 에러

| 구분 | 설명 | 예시 |
|------|------|------|
| **에러(Error)** | 복구 불가능한 심각한 문제 | `SyntaxError`, `IndentationError` |
| **예외(Exception)** | 처리 가능한 런타임 문제 | `ValueError`, `KeyError`, `FileNotFoundError` |

## 2. 기본 예외처리 문법

### 2.1 try-except 문

가장 기본적인 예외처리 방법입니다.

```python
try:
    # 예외가 발생할 수 있는 코드
    result = 10 / 0
except ZeroDivisionError:
    # 예외 발생 시 실행할 코드
    print("0으로 나눌 수 없습니다!")
```

### 2.2 여러 예외 처리

```python
try:
    number = int(input("숫자를 입력하세요: "))
    result = 10 / number
except ValueError:
    print("숫자가 아닙니다!")
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다!")
```

### 2.3 하나의 except로 여러 예외 처리

```python
try:
    # 코드
    pass
except (ValueError, TypeError, ZeroDivisionError):
    # 여러 예외를 한 번에 처리
    print("오류가 발생했습니다!")
```

### 2.4 모든 예외 처리

```python
try:
    # 코드
    result = 10 / 0
except Exception as e:
    # 모든 예외를 처리 (권장하지 않음)
    print(f"오류 발생: {e}")
```

**주의**: 모든 예외를 처리하는 것은 권장하지 않습니다. 구체적인 예외를 처리하는 것이 좋습니다.

## 3. 예외처리 고급 문법

### 3.1 try-except-else 문

예외가 발생하지 않았을 때만 실행되는 코드 블록입니다.

```python
try:
    number = int(input("숫자를 입력하세요: "))
    result = 10 / number
except ValueError:
    print("숫자가 아닙니다!")
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다!")
else:
    # 예외가 발생하지 않았을 때만 실행
    print(f"결과: {result}")
```

### 3.2 try-except-finally 문

예외 발생 여부와 관계없이 항상 실행되는 코드 블록입니다.

```python
try:
    file = open("data.txt", "r")
    content = file.read()
except FileNotFoundError:
    print("파일을 찾을 수 없습니다!")
finally:
    # 항상 실행됨 (예외 발생 여부와 무관)
    file.close()  # 파일을 항상 닫음
```

### 3.3 try-except-else-finally 문

모든 블록을 함께 사용할 수 있습니다.

```python
try:
    file = open("data.txt", "r")
    content = file.read()
except FileNotFoundError:
    print("파일을 찾을 수 없습니다!")
else:
    print("파일을 성공적으로 읽었습니다!")
finally:
    file.close()  # 항상 실행
```

### 3.4 실행 순서

```python
try:
    print("1. try 블록 시작")
    result = 10 / 2
    print("2. try 블록 끝")
except ZeroDivisionError:
    print("3. except 블록")
else:
    print("4. else 블록 (예외 없을 때)")
finally:
    print("5. finally 블록 (항상 실행)")

# 출력:
# 1. try 블록 시작
# 2. try 블록 끝
# 4. else 블록 (예외 없을 때)
# 5. finally 블록 (항상 실행)
```

### 5.2 자주 사용하는 예외

#### `ValueError`
잘못된 값이 전달되었을 때

```python
try:
    number = int("abc")  # ValueError 발생
except ValueError as e:
    print(f"값 오류: {e}")
```

#### `TypeError`
잘못된 타입이 사용되었을 때

```python
try:
    result = "hello" + 5  # TypeError 발생
except TypeError as e:
    print(f"타입 오류: {e}")
```

#### `IndexError`
리스트/튜플 인덱스가 범위를 벗어났을 때

```python
try:
    items = [1, 2, 3]
    value = items[10]  # IndexError 발생
except IndexError as e:
    print(f"인덱스 오류: {e}")
```

#### `KeyError`
딕셔너리에 존재하지 않는 키에 접근할 때

```python
try:
    data = {'name': '홍길동'}
    value = data['age']  # KeyError 발생
except KeyError as e:
    print(f"키 오류: {e}")
```

#### `FileNotFoundError`
파일을 찾을 수 없을 때

```python
try:
    with open("nonexistent.txt", "r") as f:
        content = f.read()
except FileNotFoundError as e:
    print(f"파일을 찾을 수 없습니다: {e}")
```

#### `ZeroDivisionError`
0으로 나눌 때

```python
try:
    result = 10 / 0  # ZeroDivisionError 발생
except ZeroDivisionError as e:
    print(f"0으로 나눌 수 없습니다: {e}")
```

#### `AttributeError`
존재하지 않는 속성에 접근할 때

```python
try:
    text = "hello"
    value = text.nonexistent_method()  # AttributeError 발생
except AttributeError as e:
    print(f"속성 오류: {e}")
```

## 6. 커스텀 예외 (Custom Exception)

### 6.1 기본 커스텀 예외

```python
class MyCustomError(Exception):
    """커스텀 예외 클래스"""
    pass

# 사용
try:
    raise MyCustomError("커스텀 오류 메시지")
except MyCustomError as e:
    print(f"커스텀 오류: {e}")
```

### 6.2 메시지를 포함한 커스텀 예외

```python
class ValidationError(Exception):
    """검증 오류"""
    def __init__(self, message, field=None):
        self.message = message
        self.field = field
        super().__init__(self.message)

# 사용
try:
    raise ValidationError("이메일 형식이 올바르지 않습니다", field="email")
except ValidationError as e:
    print(f"검증 오류: {e.message}, 필드: {e.field}")
```

### 6.3 예외 계층 구조

### 6.4 실전 예제

```python
class BankAccount:
    def __init__(self, balance=0):
        self.balance = balance
    
    def withdraw(self, amount):
        if amount > self.balance:
            raise InsufficientFundsError(
                f"잔액이 부족합니다. 현재 잔액: {self.balance}"

        self.balance -= amount

class InsufficientFundsError(Exception):
    """잔액 부족 오류"""
    pass

# 사용
account = BankAccount(1000)
try:
    account.withdraw(2000)
except InsufficientFundsError as e:

```

## 7. 예외 전파 (Exception Propagation)

### 7.1 예외 전파 개념

예외가 발생하면 호출 스택을 따라 위로 전파됩니다.

```python
def function_a():
    function_b()

def function_b():
    function_c()

def function_c():
    raise ValueError("오류 발생!")

try:
    function_a()
except ValueError as e:
    print(f"예외 처리: {e}")  # function_c에서 발생한 예외를 여기서 처리
```

### 7.2 예외 다시 발생시키기 (re-raise)

```python
def process_data(data):
    try:
        result = int(data)
    except ValueError:
        print("데이터 처리 중 오류 발생")
        raise  # 예외를 다시 발생시킴

try:
    process_data("abc")
except ValueError as e:
    print(f"최종 처리: {e}")
```

### 7.3 예외 변환

```python
def process_data(data):
    try:
        result = int(data)
    except ValueError as e:
        # 다른 예외로 변환
        raise TypeError(f"데이터 타입 오류: {e}") from e

try:
    process_data("abc")
except TypeError as e:
    print(f"타입 오류: {e}")
```

## 8. 예외처리 패턴

### 8.1 EAFP (Easier to Ask for Forgiveness than Permission)

"허락보다 용서를 구하는 것이 쉽다" - 파이썬의 철학

```python
# EAFP 스타일 (파이썬다운 방식)
try:
    value = my_dict['key']
except KeyError:
    value = default_value

# LBYL 스타일 (Look Before You Leap - 권장하지 않음)
if 'key' in my_dict:
    value = my_dict['key']
else:
    value = default_value
```

### 8.2 예외 무시하기

```python
# 특정 예외를 무시하고 계속 진행
try:
    result = risky_operation()
except ExpectedError:
    pass  # 예외를 무시하고 계속 진행
```

### 8.3 기본값 반환

```python
def get_value(data, key, default=None):
    try:
        return data[key]
    except KeyError:
        return default

# 또는 dict.get() 사용
value = data.get('key', default_value)
```

### 8.4 리소스 관리 (Context Manager)

```python
# 파일 처리
try:
    with open("file.txt", "r") as f:
        content = f.read()
except FileNotFoundError:
    print("파일을 찾을 수 없습니다!")
# finally가 필요 없음 - with 문이 자동으로 처리
```

### 8.5 여러 시도 (Retry Pattern)

```python
import time

def retry_operation(max_attempts=3, delay=1):
    for attempt in range(max_attempts):
        try:
            # 작업 수행
            return risky_operation()
        except Exception as e:
            if attempt == max_attempts - 1:
                raise  # 마지막 시도 실패 시 예외 발생
            print(f"시도 {attempt + 1} 실패, {delay}초 후 재시도...")
            time.sleep(delay)
```

## 9. 실전 예제

### 9.1 파일 처리

```python
def read_file_safely(filename):
    """안전하게 파일 읽기"""
    try:
        with open(filename, 'r', encoding='utf-8') as f:
            return f.read()
    except FileNotFoundError:
        print(f"파일을 찾을 수 없습니다: {filename}")
        return None
    except PermissionError:
        print(f"파일 읽기 권한이 없습니다: {filename}")
        return None
    except UnicodeDecodeError:
        print(f"파일 인코딩 오류: {filename}")
        return None
    except Exception as e:
        print(f"예상치 못한 오류: {e}")
        return None
```

### 9.4 데이터베이스 작업

```python
import sqlite3

def execute_query(db_path, query, params=None):
    """데이터베이스 쿼리 실행"""
    try:
        conn = sqlite3.connect(db_path)
        cursor = conn.cursor()
        cursor.execute(query, params or ())
        result = cursor.fetchall()
        conn.commit()
        return result
    except sqlite3.OperationalError as e:
        print(f"데이터베이스 오류: {e}")
        return None
    except sqlite3.IntegrityError as e:
        print(f"무결성 오류: {e}")
        return None
    finally:
        if conn:
            conn.close()
```

## 12. 예외처리와 성능

### 12.1 예외처리 비용

예외처리 자체는 비용이 거의 없지만, 예외가 자주 발생하면 성능에 영향을 줄 수 있습니다.

```python
# 나쁜 예 - 예외를 흐름 제어로 사용
try:
    value = data[key]
except KeyError:
    value = default  # 예외가 자주 발생하면 비효율적

# 좋은 예
value = data.get(key, default)  # 예외 없이 처리
```

### 12.2 예외 vs 조건문

```python
# 예외가 자주 발생하는 경우 - 조건문 사용
if key in data:
    value = data[key]
else:
    value = default

# 예외가 드문 경우 - 예외처리 사용
try:
    value = data[key]
except KeyError:
    value = default
```

## 13. 특수한 예외처리

### 13.1 KeyboardInterrupt 처리

```python
try:
    while True:
        # 긴 작업
        process_data()
except KeyboardInterrupt:
    print("\n작업이 중단되었습니다.")

```

### 13.2 SystemExit 처리

```python
import sys

try:
    if some_condition:
        sys.exit(0)  # 정상 종료
except SystemExit:
    print("프로그램이 종료됩니다.")
    cleanup()
```

### 13.3 AssertionError

```python
def divide(a, b):
    assert b != 0, "0으로 나눌 수 없습니다!"
    return a / b

try:
    result = divide(10, 0)
except AssertionError as e:
    print(f"단언 오류: {e}")
```

## 15. 요약

### 핵심 개념

1. **try-except**: 기본 예외처리
2. **else**: 예외 없을 때 실행
3. **finally**: 항상 실행
4. **raise**: 예외 발생시키기
5. **커스텀 예외**: 프로젝트별 예외 정의

### 주요 예외 타입

- `ValueError`: 값 오류

- `IndexError`: 인덱스 오류
- `KeyError`: 키 오류
- `FileNotFoundError`: 파일 없음
- `ZeroDivisionError`: 0으로 나눔
