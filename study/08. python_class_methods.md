## 1. 인스턴스 메서드 (Instance Method)

### 기본 인스턴스 메서드

```python
class Calculator:
    def __init__(self, value: int = 0):
        self.value = value
    
    def add(self, num: int) -> int:
        """
        인스턴스 메서드
        self: 첫 번째 파라미터로 항상 필요
        """
        self.value += num
        return self.value
    
    def subtract(self, num: int) -> int:
        """빼기 메서드"""
        self.value -= num
        return self.value
```

### 가변 인자를 받는 메서드

```python
class MathUtils:
    def calculate(self, operation: str, *numbers: float) -> float:
        """가변 인자를 받는 메서드"""
        if operation == "add":
            return sum(numbers)
        elif operation == "multiply":
            result = 1
            for num in numbers:
                result *= num
            return result
        else:
            raise ValueError(f"Unknown operation: {operation}")

# 사용 예시
math = MathUtils()
result1 = math.calculate("add", 1, 2, 3, 4)  # 10
result2 = math.calculate("multiply", 2, 3, 4)  # 24
```

## 2. 클래스 메서드 (Class Method) - `@classmethod`

```python
class Person:
    count = 0  # 클래스 변수
    
    def __init__(self, name: str):
        self.name = name
        Person.count += 1
    
    @classmethod
    def get_count(cls) -> int:
        """
        cls: 클래스 자체를 참조 (self 대신 cls 사용)
        클래스 변수나 다른 클래스 메서드 접근 시 사용
        """
        return cls.count
    
    @classmethod
    def create_baby(cls, name: str) -> 'Person':
        """
        팩토리 메서드 패턴
        클래스 메서드로 인스턴스를 생성하여 반환
        """
        baby = cls(name)
        baby.age = 0
        return baby

# 사용 예시
person1 = Person("홍길동")
person2 = Person("김철수")
print(Person.get_count())  # 2

baby = Person.create_baby("아기")
```

## 3. 정적 메서드 (Static Method) - `@staticmethod`

```python
class MathHelper:
    @staticmethod
    def add(a: int, b: int) -> int:
        """
        self나 cls 없이 독립적인 함수처럼 동작
        클래스와 관련된 유틸리티 함수로 사용
        """
        return a + b
    
    @staticmethod
    def is_even(num: int) -> bool:
        """짝수 판별"""
        return num % 2 == 0

# 사용 예시
result = MathHelper.add(5, 3)  # 8
print(MathHelper.is_even(4))  # True

# 인스턴스로도 호출 가능
helper = MathHelper()
result = helper.add(2, 3)  # 5
```

## 4. 메서드 종류 비교

| 메서드 종류 | 데코레이터 | 첫 파라미터 | 접근 대상 | 사용 예시 |
|------------|-----------|------------|----------|----------|
| 인스턴스 메서드 | 없음 | `self` | 인스턴스 변수/메서드 | `obj.method()` |
| 클래스 메서드 | `@classmethod` | `cls` | 클래스 변수/메서드 | `Class.method()` |
| 정적 메서드 | `@staticmethod` | 없음 | 독립적 동작 | `Class.method()` |

## 5. 실제 사용 예시

```python
from typing import Optional, List
from datetime import datetime

class BankAccount:
    """은행 계좌 클래스"""
    
    # 클래스 변수
    account_count = 0
    interest_rate = 0.02
    
    def __init__(self, owner: str, initial_balance: float = 0.0):
        """인스턴스 메서드 (생성자)"""
        BankAccount.account_count += 1
        self.account_number = BankAccount.account_count
        self.owner = owner
        self._balance = initial_balance
        self.transaction_history: List[str] = []
    
    def deposit(self, amount: float) -> float:
        """인스턴스 메서드"""
        if amount <= 0:
            raise ValueError("입금 금액은 0보다 커야 합니다")
        self._balance += amount
        self.transaction_history.append(
            f"{datetime.now()}: 입금 {amount:,.0f}원"
        )
        return self._balance
    
    @classmethod
    def get_account_count(cls) -> int:
        """클래스 메서드"""
        return cls.account_count
    
    @classmethod
    def set_interest_rate(cls, rate: float) -> None:
        """클래스 메서드"""
        cls.interest_rate = rate
    
    @staticmethod
    def calculate_interest(principal: float, years: int) -> float:
        """정적 메서드"""
        return principal * BankAccount.interest_rate * years
    
    def get_transaction_history(self, limit: Optional[int] = None) -> List[str]:
        """인스턴스 메서드"""
        if limit is None:
            return self.transaction_history
        return self.transaction_history[-limit:]

# 사용 예시
account1 = BankAccount("홍길동", 10000)
account2 = BankAccount("김철수", 5000)

print(BankAccount.get_account_count())  # 2 (클래스 메서드)
print(BankAccount.calculate_interest(10000, 1))  # 200.0 (정적 메서드)

account1.deposit(5000)  # 인스턴스 메서드
print(account1.get_transaction_history(1))  # 인스턴스 메서드
```

## 6. 언제 어떤 메서드를 사용할까?

### 인스턴스 메서드
- 인스턴스 변수에 접근하거나 수정할 때
- 각 객체마다 다른 동작을 해야 할 때

### 클래스 메서드
- 클래스 변수에 접근하거나 수정할 때
- 팩토리 메서드로 다른 생성자를 만들 때
- 클래스 레벨의 유틸리티 함수가 필요할 때

### 정적 메서드
- 클래스와 관련이 있지만 인스턴스나 클래스 변수에 접근할 필요가 없을 때
- 독립적인 유틸리티 함수로 사용할 때
